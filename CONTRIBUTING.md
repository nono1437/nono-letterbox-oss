# Contributing to Nono Letterbox OSS

Thank you for helping make the little house safer and easier to use. 🌸

## Good first contributions

- reproduce and describe a mobile UI problem;
- improve setup or privacy documentation;
- suggest an accessibility improvement;
- add or refine demo-only content;
- fix a small local-storage, backup, search, or navigation bug.

## Before opening an issue

1. Check whether the problem has already been reported.
2. Remove real email addresses, message text, tokens, account IDs, and private attachments from screenshots or logs.
3. Include the device/browser, steps to reproduce, expected result, and actual result.

## Pull requests

- Keep each pull request focused on one change.
- Do not add telemetry, hidden uploads, unofficial credential forwarding, or hard-coded personal accounts.
- Do not commit generated Android builds, signing keys, `.env` files, or personal backups.
- Run the documented checks before requesting review.
- Explain what changed, why it changed, and how it was tested.

## AI-assisted contributions

AI-assisted code is welcome, but the contributor remains responsible for reviewing it, testing it, and confirming that it does not expose private data or introduce copied code with an incompatible license.

## Project direction

The first milestone is deliberately small and dependable:

`demo letters → search/favorite → local replies → backup export`

Large integrations should wait until this flow is stable and privacy boundaries are clear.
