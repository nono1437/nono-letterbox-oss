# Third-party assets

## Codex built-in pet

The animated Codex companion uses OpenAI's versioned built-in Codex pet spritesheet:

- Source: `https://persistent.oaistatic.com/codex/pets/v1/codex-spritesheet-v4.webp`
- Geometry: 8 columns × 9 rows, 192 × 208 pixels per frame
- Downloaded during `npm run build` and bundled into the generated web/Android application
- The binary is intentionally not committed to this repository

The surrounding letterbox application is an independent community project. It is not an official OpenAI application, and the repository's MIT license does not claim ownership of the Codex pet artwork or OpenAI marks.
